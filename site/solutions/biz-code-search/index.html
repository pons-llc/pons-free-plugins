kintoneで法人番号を自動取得する方法

取引先アプリなどで法人番号や会社情報を手入力していると、入力ミスや二度手間が発生しがちです。 国が公開しているgBizINFOのデータを使えば、法人番号や法人名から会社情報を自動入力できます。 このページでは、そのための無料プラグインを紹介します。

こんな方におすすめ

  • 法人番号から会社情報を自動入力したい
  • 法人名から法人番号を検索したい
  • gBizINFOをkintoneから利用したい
  • 取引先情報の入力を効率化したい
  • 無料で法人番号検索機能を追加したい

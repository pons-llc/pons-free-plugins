アプリ間突合プラグイン 設定

基準アプリのレコードを対象者一覧として、対象アプリそれぞれに同じ人のレコードがあるかを突き合わせ、 「提出済 / 未提出」の一覧をこのアプリのレコードに保存します。 実行のたびに結果はJSONファイルとして「突合履歴」テーブルに1行ずつ追記され、 レコード詳細画面のドロップダウンから過去の実行結果を切り替えて表示できます。

1. 集計用フィールド

結果を保存するための「突合履歴」テーブルと、結果を表示するスペースをこのアプリに作成します。 この操作を実行すると、アプリの設定が運用環境へ反映(デプロイ)されます。 動作テスト環境に未反映の変更がある場合、それらも同時に公開されます。

2. 基準アプリ(対象者の母集団)

「誰が対象者か」を決めるアプリです。例:「妊娠届」アプリ。ここに登録されている人が突合結果の各行になります。



個人番号・宛名番号など、人を一意に特定できるフィールドを選びます。


結果一覧に氏名などを併記したい場合に選びます(任意)。


kintoneのクエリ記法で書きます。空欄なら全レコードが対象です。

3. 対象アプリ(提出状況を調べるアプリ)

基準アプリの人が「出しているかどうか」を調べるアプリです。例:「妊娠時面談予約」アプリ。複数指定できます。

4. 表示と上限




アプリ1つあたりの上限です。超えた分は突合されません。


超えた分は古い実行結果から削除されます。

帳票ビルダープラグイン 設定

見積書などの帳票を、外部の生成AIを使わずこのプラグインだけで直接出力します(ノーコード)。 ページごとに12列のグリッドへフィールド・テーブル・自由テキストをドラッグ&ドロップで配置してください。 用紙サイズはA4縦で固定です。

対応する出力方法必須

少なくとも1つ選択してください。

添付ファイルへの保存(任意)

個別出力時に、生成した帳票をPDFとしてレコードの添付ファイルフィールドにも保存できます。

このアプリには添付ファイルフィールドがありません。

実際のファイル名は「固定部分+保存日時」になります(例: 「帳票」なら「帳票_20260305093000.pdf」)。

ページ構成必須

このアプリには帳票に使えるフィールドがありません。
